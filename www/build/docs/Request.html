Request

classe Request

Encapsuler les données de requête HTTP.

La classe centralise les superglobales PHP, les en-têtes, le corps de requête (formulaire, fichiers, flux JSON/url-encoded) et expose des helpers de lecture sûrs pour les contrôleurs.

Propriétés

string $type

array<string,mixed> $data

Données POST fusionnées avec les fichiers uploadés et le flux brut.
array<string,mixed> $query

Paramètres de chaîne de requête.
string $url

URL complète de la requête (avec host mais sans protocole explicite).
